# Architecture Decision Records

Formato [MADR 4](https://adr.github.io/madr/). Un ADR no se edita una vez aceptado: si cambia la decisión, se crea uno nuevo que lo sustituye.

|---|---|---|
| [0001](0001-yaml-as-project-format.md) | YAML como formato de los proyectos (frente a tfvars y JSON) | aceptado |
| [0002](0002-deployment-unit.md) | Proyecto × entorno = un root, un state, una suscripción | aceptado |
| [0003](0003-engine-versioning.md) | Versionado del motor con SemVer y pin exacto por proyecto | aceptado |
| [0004](0004-two-layer-validation.md) | Validación en dos capas y forma del YAML | aceptado |
| [0005](0005-identities-and-permissions.md) | Identidades del pipeline, grupos de Entra ID y acceso al state | aceptado |
